# Selitve Mormo, spletna stran

Next.js 16 (App Router, TypeScript), Tailwind CSS 4, statically generated. One API route for inquiries. No database, no CRM.

```bash
npm install
cp .env.example .env.local   # fill in, see below
npm run dev                  # http://localhost:3000
npm run build && npm start   # production build
```

## Where things live

| What | File |
|---|---|
| Phone, brand name, domain, service area, company data, partner link, team, vehicles | `config/site.ts` (the only place the phone number is set) |
| Service pages (8) | `content/services.ts`, rendered by `app/[storitev]/page.tsx` |
| Homepage copy: process, reasons, FAQ, checklist, wizard options | `content/home.ts` |
| Inquiry wizard | `components/inquiry/InquiryWizard.tsx` (+ `Calendar.tsx`, `RouteMap.tsx`) |
| Inquiry API, validation, email | `app/api/povprasevanje/route.ts`, `lib/inquiry.ts`, `lib/email.ts`, `lib/rate-limit.ts` |
| Structured data | `lib/schema.ts` |
| Hero video files | `public/hero/` (as supplied, not re-encoded) |
| Design tokens and components | `app/globals.css` |
| Map data | `data/*.json`, generated by `scripts/build-geo.mjs` |

## Environment variables

| Name | Required | Purpose |
|---|---|---|
| `NEXT_PUBLIC_SITE_URL` | yes | Production URL without trailing slash. Canonicals, sitemap, JSON-LD, www redirect. |
| `RESEND_API_KEY` | yes | Resend API key. Without it the API answers with an error and the form shows the failure message (never a fake success). |
| `INQUIRY_FROM` | yes | Sender on a domain verified in Resend, e.g. `Selitve Mormo <povprasevanje@selitve-mormo.si>`. |
| `INQUIRY_TO` | no | Recipient(s), comma-separated. Default `luka@mormo.si`. |
| `INQUIRY_DRY_RUN` | dev only | `1` logs inquiries to the console instead of sending. Ignored in production. |

## Email delivery

1. Create a Resend account, add the domain (e.g. `selitve-mormo.si`) and add the DNS records it shows (SPF, DKIM). Wait until it is verified.
2. Create an API key with "sending" permission and set the env vars above.
3. Submit a test inquiry on the live site and confirm it arrives at `luka@mormo.si`. The customer's email (if given) is set as Reply-To.

The route checks: same origin, rate limit (5 per 10 min per IP, per server instance), hidden honeypot field, minimum fill time, server-side validation of every field. Success is returned only after Resend accepts the message.

## Deploy (Vercel)

1. Import the repository, framework preset Next.js. Set the env vars for Production.
2. Add both `selitve-mormo.si` and `www.selitve-mormo.si`; set the apex as primary (Vercel redirects www). `next.config.ts` also redirects www to apex.
3. `/hero/*` is served with `Cache-Control: public, max-age=31536000, immutable` and byte ranges. If the video ever changes, give the file a new name (e.g. `selitve-hero-1080.v2.mp4`).

## Route map and distances

- Outline of Slovenia: geoBoundaries gbOpen ADM0 (public domain).
- Towns (40): geocoded with OpenStreetMap Nominatim.
- Distances: OSRM driving table on OpenStreetMap roads, between town centres, rounded to km. Straight-line distance is never shown.
- Motorways on the map: real OSRM route geometry between motorway end points, simplified.
- An address or town not in the list: "Razdaljo preverimo ob pripravi ponudbe." "Tujina": "Kilometri po dogovoru."
- To add towns, edit `PLACES` in `scripts/build-geo.mjs`, run `npm run geo`, commit `data/`.

## Search Console and monitoring

1. Google Search Console: add a **Domain property** for the domain (DNS TXT verification).
2. Submit `https://<domain>/sitemap.xml`.
3. URL Inspection: inspect `/` and two service pages, "Request indexing".
4. Check structured data with the Rich Results Test and validator.schema.org (MovingCompany, WebSite, Service, BreadcrumbList, FAQPage). FAQ rich results are limited by Google; the markup is still valid.
5. Bing Webmaster Tools: import from Search Console (Bing also feeds ChatGPT search and Copilot).
6. Monitor: Search Console > Performance (queries such as "selitveni servis ljubljana"), Pages (indexing), Core Web Vitals.
7. Create a Google Business Profile as a **service-area business** (no public address), same name, phone and URL as the site.

`robots.txt` allows all crawlers, including AI search crawlers. To opt out of model training only, see the comment in `app/robots.ts`.

## Analytics

None installed, so no cookie banner is needed. `lib/track.ts` sends `phone_click`, `sms_click`, `inquiry_started`, `inquiry_step_completed`, `inquiry_submitted`, `contact_form_submitted` to Plausible or a GTM `dataLayer` if one is added. `inquiry_submitted` fires only after a confirmed server success. If you add analytics, update `app/zasebnost/page.tsx`.
